# Info
n	 logger name		
l	 level		
L	 short level

t	 thread id		
P	 pid		

v	 the message text

# Time
H	 hours 24		
I	 hours 12		
M	 minutes		
S	 seconds		
e	 milliseconds		
f	 microseconds		
F	 nanoseconds		
E	 seconds since epoch		
p	 am	pm	
r	 12 hour clock 02:55:02 pm		
R	 24-hour HH:MM time		
T/X	 ISO 8601 time format (HH:MM:SS)		
z	 timezone	

---- 
# Date
a	 weekday		
A	 short weekday		
b/h	 month		
B	 short month		
c	 datetime		
C	 year 2 digits		
Y	 year 4 digits		
D/x	 datetime MM	DD	YY
m	 month 1-12		
d	 day of month 1-31

# Others
&			
+	 default formatter		
^	 color range start		
$	 color range end		
%	 % char		
u	 elapsed time since last log message in nanos		
i	 elapsed time since last log message in micros		
o	 elapsed time since last log message in millis		
O	 elapsed time since last log message in seconds

s	 short source filename - without directory name		
g	 full source filename
